# Retail Price Intelligence — Do Ratings Affect Book Prices?

**books.toscrape.com · 999 books · 50 categories**

Started this to learn scraping but ended up with a finding I didn't expect: rating and price are basically unrelated on this platform (Spearman ρ ≈ 0.03). Genre drives price, not quality signals.

---

## How to Run

```bash
pip install -r requirements.txt
python scripts/scraper.py       # scrape ~1,000 books  → data/raw/raw_books.csv
python scripts/clean.py         # clean + flag duplicates → data/cleaned/books_clean.csv
python scripts/stats.py         # statistical tests → output/reports/stats_summary.txt
jupyter notebook notebooks/EDA.ipynb          # exploratory analysis + charts
jupyter notebook notebooks/visualization.ipynb # advanced visualizations
```

> **Note:** Run all scripts from the project root directory so relative paths resolve correctly.

## Key Findings

| Metric | Value |
|--------|-------|
| Books after cleaning | 999 |
| Median price | £36.00 |
| Mean price | £35.07 |
| Std deviation | £14.45 |
| Min / Max | £10.00 / £59.99 |
| Spearman ρ (rating vs price) | 0.0296 |
| Spearman p-value | 0.3505 |
| Kruskal-Wallis H | 1.5736 |
| Kruskal-Wallis p-value | 0.8135 |

Price is broadly uniform (£10–£60). Category is the real price driver — Suspense and Novels have a median above £54; Crime and Academic sit at £11–13. Within any single category, a 5-star book costs almost the same as a 3-star one.

---

## Business Insights

1. Prices spread £10–£60 with no clustering — no dominant price point on this platform.
2. Star ratings have no pricing signal (ρ = 0.03). Price is not a proxy for quality here.
3. Genre explains price far better than rating. Category median prices differ by up to £45.
4. 52% of books fall in the high price tier (>£35); only 20% in the low tier (<£20).
5. All five rating groups are roughly balanced (196–226 books each), so the results are not skewed by uneven sample sizes.

## Limitations

- books.toscrape.com uses synthetic, fixed prices. The pricing patterns found here may not hold on a real marketplace.
- Single scrape — no way to analyse price drift over time.
- Only 50 categories, some with very few books (as few as 1–2 titles), which makes per-category stats unreliable for small categories.
